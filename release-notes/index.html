    Releases

    0.9.0 (unreleased)

    Contour is now daemon-first: a plain contour shows sessions a daemon hosts, starting it when none runs, so closing the window no longer ends your shells. Reopen Contour, or attach from another machine over ssh or TLS, and they are still there. Set

    Its window and Settings are redesigned to feel native on macOS, Windows 11 and Linux, with a Terminal style of their own, a command palette, command blocks, split panes with cards and a status line.

    • Adds the Connect picker, a small window that asks where a window's sessions should live before any terminal window opens: this computer's daemon (with its state and session count), this window only, a saved host, or an ssh:// or tls:// address typed in its field. Type to filter, press Return to connect, Escape to cancel, Alt+1 to Alt+9 (⌘1 to ⌘9 on macOS) to connect to the row shown with that number; a connection that fails stays under its row, in the words Attach to Host uses, with Retry and Edit Host…. It starts on the last target used
    • Adds File › New Window to… (Ctrl+Shift+K, ⇧⌘K on macOS), the NewWindowTo action, which opens the picker as a sheet; contour connect [TARGET], where TARGET is daemon[:LABEL], local, a saved host's name or an ssh:// or tls:// address and no target shows the picker; and contour connect --list [--json]
    • Adds the connect_picker_on_start setting (Settings › General, and the picker's "Ask every time Contour starts"), which makes a launch without arguments, as a Dock, Spotlight or launcher start is, show the picker first
    • Adds a "Connect…" action to the Linux desktop entry and a "Contour — Connect…" launcher, a "New Window to…" entry and the saved hosts to the macOS Dock menu, and "Connect…" and the saved hosts to the Windows jump list, with a "Contour (Connect…)" Start menu shortcut
    • Panes have default shortcuts out of the box: Alt+Shift+Arrow moves the focus (Cmd+Option+Arrow on macOS), Ctrl+Shift+E and Ctrl+Shift+O split (Cmd+D and Cmd+Shift+D on macOS), and Cmd+Shift+Enter zooms a pane on macOS. A configuration written by an earlier release picks them up too
    • The command palette's and the Settings window's selected row keeps the desktop's highlight colour but takes white or black text, whichever reads better, where the desktop's own text would fall under 4.5:1 (KDE Breeze's blue under white)
    • On Windows 11 the tabs are the title bar, on Mica, with tabs that join the terminal below them; the Settings window's title bar is Mica too and follows the chrome's light or dark
    • Hovering the maximise button opens Windows 11's Snap Layouts
    • Windows caption buttons use the Segoe Fluent icons, and the Windows chrome uses Segoe UI Variable and the FluentWinUI3 controls
    • Contour follows Windows' animation, transparency-effects, contrast-theme and accent settings, live
    • On Windows 10, and with transparency effects off, the title bar is solid
    • Rounds the in-window menus on every platform to its own menu radius (10 px on Linux and macOS, up from 3), with row highlights rounded to match
    • Draws command blocks as a rail beside the output: neutral for success (✓ on hover), red with ✗ for a failure, the accent with ▸ while running, in a fixed strip after the line numbers and timestamps
    • Shows how a command went right of its prompt, only where those cells are blank, so an RPROMPT is never covered
    • Adds a ⋯ button and a native block menu (Copy Output, Copy Command, Rerun, Open in Pager, Collapse Output) whose header names the command and how it ended; the block tooltip is gone
    • Adds ⌘↑/⌘↓ to step through command blocks, ⇧⌘↑/⇧⌘↓ to select their output, and Ctrl+Enter or Shift+F10 to open a focused block's menu; VoiceOver says how each command went. Adds the FocusPreviousCommand, FocusNextCommand, SelectPreviousCommandOutput, SelectNextCommandOutput, OpenBlockMenu, ClearCommandBlockFocus and ToggleCommandFold actions and the BlockFocus input mode
    • Folded output reads "80 lines hidden ⌄"; the sticky command header moves into the pane header or the title band
    • Draws scrollbar ticks as solid for failures, hollow for running commands and yellow for search matches; scrollbar.marks gains running and search_matches
    • Moves keyboard focus into the tab bar and toolbar with Ctrl+F6 (Ctrl+Shift+F6 backwards), and on macOS to the toolbar with Ctrl+F5; in the tab bar the arrow keys move, Return activates, Backspace closes (asking first if a program may still be running) and Alt+Left or Alt+Right reorders, and a ring marks the focused item. A bare F6 still goes to the shell, and so does Ctrl+F6 when the window shows no tab bar or toolbar. Adds the actions FocusNextArea, FocusPreviousArea and FocusToolbar
    • Makes Ctrl+C and Ctrl+V clear the selection after copying or pasting under the built-in bindings, where it used to stay selected, as a generated configuration file already did
    • Offers to install shell integration for bash, zsh and fish when a shell writes no prompt marks: the card shows the one line it would add to the shell's rc file, and adds it only when asked
    • Shows and installs shell integration per shell in Settings › Shell Integration
    • Marks the history a restored pane brings back with a "Restored · session ended hh:mm" divider, ends a command that was still running at the snapshot as abandoned, and says once how many windows and tabs the daemon restored
    • Inserts the shell-escaped paths of files dropped on a pane, quoted for the program in the foreground and never run. A pane whose foreground program is not a known POSIX shell, PowerShell or cmd (every pane on Windows and every pane hosted by the daemon, and a multiplexer, ssh or another shell) refuses a dropped file name or link that holds a shell metacharacter, such as a quote, an apostrophe, a parenthesis, &, % or $, so a name like John's.txt is not typed there
    • Splits a pane when a tab is dropped on its outer edge, showing where the tab will go; a tab dropped in a pane's middle tears off into a new window as before
    • Shows the size indicator as a pill centred on each resized pane ("100 × 30", or "13 pt" while zooming the font), announced once to screen readers when it settles
    • Makes the scrollbar an overlay that follows the system's scroll bar setting and hides at the bottom of the scrollback unless a failed or running command or a mark lies above; adds scrollbar.mode (system, overlay, always)
    • Replaces the hyperlink tooltip with a target pill shown while the follow modifier is held, placed in the pane header or over blank cells and never on the prompt row; hyperlink_hover_tooltip now shows it on plain hover and is off in the new defaults
    • Draws hint-mode labels in the cursor colour under contour-dark and contour-light, dims everything else, and turns the labels to the selection colour once a prefix is typed; adds the hint_label_typed scheme key
    • Changes Settings to open in a window of its own, one per app, from Settings… in the Contour menu (⌘, on macOS, Ctrl+Shift+, elsewhere), the command palette or the OpenConfiguration binding. It opens with or without a terminal window, is brought forward when asked for again, and reopens where it was left
    • Removes the Settings tab from the tab strip and the Settings entry from the new-tab menu
    • Rebuilds the Settings window as General, Appearance, Keyboard, Shell Integration and Profiles, with a search field and an Edit contour.yml… entry; rows use switches, segmented controls, steppers, sliders, a font picker and color wells, in the look of each platform
    • Applies every Settings change at once and writes it to the profile's or the global side file within 300 ms, replacing the file whole; Revert Changes undoes the session's edits. A file changed in an editor meanwhile is never overwritten, and Settings shows that version instead. Profiles and color schemes defined in contour.yml stay read-only, with Duplicate to Edit
    • Adds a Hosts section to Settings, after Profiles: saved hosts are added, edited, renamed, duplicated and removed there and written to hosts/<name>.yml beside contour.yml, and appear under Attach to Host. A host's page shows the SSH or TLS fields its address calls for, says under a field what the loader would refuse in the loader's own words and saves nothing until it is fixed, and attaches a window to the host with Attach. Hosts defined in contour.yml stay read-only, with Duplicate to Edit
    • Shows a live terminal preview at the top of every profile page that follows each change before it is written
    • Turns the color scheme, link pattern and status line editors into pages of a profile, with a gallery of schemes, a contrast readout on every color well that says whether it reads, and renaming a scheme that moves the profiles drawing with it; the Status Line fields are on both the profile's page and the Status Line page
    • Adds Settings rows for the scrollbar's mark sources (failed, other, running and user-marked commands, and search matches), secure_input, input_method_editor_style and scrollbar.mode
    • Makes option_as_alt take off, left, right or both, so one Option key can type accents while the other acts as Alt; true and false are still read, as both and off
    • Reopens Settings on the page it was left on, and refuses a new profile or color scheme name a configuration folder could not carry to Windows, such as con or nul; an existing profiles/aux.yml or nul.yml still loads on Linux and can be edited and deleted
    • Adds macOS tabs as pills in a tab well within the title band, with a centred title while there is one tab
    • Adds one badge per tab for unseen output, finished commands and OSC 7501 program status, by priority: waiting, failed, working, done, new output. 'Working' and progress now use the accent colour
    • Changes the remote host label into a host chip that shows when the connection is reconnecting or lost
    • Moves the daemon version notice from over the terminal into the title bar
    • Reveals the tab bar in full screen when the pointer reaches the top edge, as a cross-fade under Reduce Motion
    • Shows the foreground process's name on a tab whose title is empty
    • Fixes a background remote tab showing new output when it reconnects or resyncs; a program's own screen switch or clear in it still marks it
    • Adds a native macOS menu bar of six menus: Contour, Shell, Edit, View, Window and Help. The Window menu lists the open windows, and Help carries the system's search field
    • Adds native context menus on macOS: with the default ui_style: native, the terminal, title bar, tab and new-tab menus open as system menus; ui_style: terminal keeps the in-window menus
    • Adds a row of color swatches and Move Tab to New Window to the tab's context menu
    • Changes the in-window tab menu (on Linux and Windows, and under ui_style: terminal) to open below the tab instead of at the pointer
    • Adds the actions CloseOtherTabs, CloseTabsToRight, MoveTabToNewWindow, ShowAbout, MinimizeWindow and ZoomWindow
    • Changes key handling under the macOS menu bar: the terminal now receives every key chord except the menu's own (⌘Q, ⌘,, ⌘H, ⌥⌘H and ⌘M), including chords a menu item shows
    • Fixes a configuration with separate light and dark color schemes being saved as YAML that did not load back
    • Changes the notice shown while a window runs its shells itself, because the daemon could not be reached, into a banner that pushes the terminal down instead of covering its first line
    • Changes the window chrome under theme: terminal with a single color scheme to follow the focused terminal's background, including one a program sets with OSC 11
    • Adds Reduce Motion support on macOS: with it on, the cursor glide and the screen transition are skipped, and turning it off restores the configured durations
    • Shows a lock on the tab, in the pane header or in a pill over the pane while a program hides what you type, such as a password prompt, and turns on Secure Keyboard Entry on macOS for as long as that pane has focus; panes hosted by a daemon report it too. Adds secure_input (auto, off)
    • Adds a one-time offer of the new defaults to a configuration that states no defaults_edition, and after Reset Config; it is never shown for an explicit classic, a locked configuration or a settings.yml that does not parse
    • Changes the first-launch defaults, for a newly generated configuration only (defaults_edition: native2026): JetBrains Mono (Cascadia Mono on Windows) at 13 pt on macOS and 12 pt elsewhere, a 100×30 window with small margins, the contour-light and contour-dark color schemes following the system appearance, the indicator status line, the tab bar once there is a second tab, a silent bell, 10000 lines of scrollback, a steady block cursor and Command+click to follow links on macOS. An existing configuration without the key keeps every previous default
    • Changes the default theme to terminal: the window chrome turns light or dark with the default profile's background
    • Changes the focus frame to appear only in a split tab, where it tells the active pane apart, and to use the system highlight color
    • Changes a running command block's derived status color from yellow to blue, so it no longer reads as a search match
    • Adds the built-in color schemes contour-dark, contour-light and contour-classic, every text color of which stays readable on its background
    • Adds Command, Option, Shift and Control glyphs (⌘⌥⇧⌃) to shortcuts shown in the command palette and the settings page on macOS
    • Bundles the JetBrains Mono font (SIL Open Font License 1.1) on macOS and Linux, so the default font is present without installing it
    • Keeps the input method's candidate window at the cursor cell, including at the end of a line and while panes move or the font changes, instead of the pane's corner
    • Draws text being composed by an input method inline, at the cursor, or to its left when it would not fit, in the terminal's default colours with a thin (one logical point) underline, in the new defaults; adds input_method_editor_style (inline, highlighted)
    • Fixes text being composed by an input method not being shown on a line of plain text, and running off the right edge of the line; at the end of a line it now moves left to stay in view
    • Names the command a daemon restart stopped in each restored pane, with Run Again (after asking) and Dismiss
    • Offers Reconnect in a pane that lost its daemon connection
    • Daemon: every window, tab and pane has a stable UUID, and each hosted shell finds its own with $CONTOUR_PANE, $CONTOUR_TAB, $CONTOUR_WINDOW and $CONTOUR_DAEMON.
    • Daemon: serves a typed control API on its native socket: list, capture and label windows, tabs and panes, open tabs and splits, type into panes, read and wait for command blocks, and subscribe to events.
    • Daemon: contour daemon --access-file FILE issues TCP tokens with narrower control API grants (read, screen, input, write); a call outside them is refused as forbidden, and a narrow token cannot attach.
    • Daemon: a new daemon: configuration section, and --daemon-mode per launch, choose where sessions are hosted: auto (the default) in a daemon with an in-process fallback and a notice when none can be reached, in_process in the window's own process, required in a daemon or not at all; socket, size_policy and history_limit configure the daemon itself.
    • Daemon: a plain contour now shows sessions that a daemon hosts, starting it when none runs, so closing the window no longer ends your shells; set daemon: { mode: in_process } or pass --daemon-mode in_process to keep them in the window as before.
    • Daemon: a window attached to a daemon survives a lost connection: its panes show "Reconnecting…" while it reconnects with backoff, a connection gone half-open is noticed by a heartbeat, input typed meanwhile is dropped rather than replayed, and a pane closed meanwhile is closed on the daemon once it answers.
    • Daemon: contour client --window N shows one daemon window; a tab's profile is resolved in the daemon's configuration, and its active pane, zoom, title and color reach every other attached client; a client smaller than the shared grid follows the cursor.
    • Daemon: picks up edits of its configuration file without a restart: new sessions use the edited profiles, and running ones take the new scrollback limits.
    • Extensions: a status-line extension that contour daemon hosts can call the control API: list, open, split, close and label windows, tabs and panes, type into panes, and read panes and command blocks. Its manifest declares what it needs (control read, screen, input or write), the permission prompt lists each, and the answer covers the extension's commands too; the WIT package terminal-extensions:control@0.1.0 in wit/control describes the calls. An older Contour attached to the daemon is not asked about such an extension, whose commands then stay ungranted until a current one answers
    • CLI: contour ls, new, split, send, pane capture, close, label and api list, describe and call script the daemon's windows, tabs and panes, with --json output and distinct exit statuses; contour block list and read, wait, and events read command blocks and follow events.
    • CLI: contour agent setup installs a generated skill that teaches Claude Code, Codex and other coding agents to operate Contour panes.
    • Adds OSC 7501 program status: a program reports that it is working, done, blocked on the user or failed, and each terminal keeps up to 64 such records, dropping working and blocked ones at the next prompt or when the process exits.
    • Daemon: mirrors each pane's OSC 7501 program status to attached clients, lists it in contour ls --json and emits pane.programStatusChanged events.
    • The tab strip shows a badge for a tab whose program is working, waiting for the user, done or failed (OSC 7501), with the program's message as its tooltip, invisible formatting characters removed.
    • DEC mode 2034's SBQUERY answers an older command block by its id (Ps 4), and its JSON, now version 2, gives each block its id, working directory, start time and duration; every version 1 field is unchanged.
    • Adds the status-line placeholders {Cwd}, {Git} (read from .git/HEAD, no process spawned), {LastCommand}, {Selection} and {Scroll}
    • Adds color roles to the status line: a color may name a scheme role (Color=accent|success|danger|warning|muted), so one template reads well in every scheme; hex colors still work
    • Adds Hide=<mode> and Chip to {InputMode}, and MaxWidth= to {Cwd} and {LastCommand}
    • Changes a status line too wide for its pane to drop its least important items first, right to left
    • Changes the new default status line to show where you are, the branch, how the last command went and the scroll position
    • Paints the macOS tab bar in a tint of the terminal background, solid also under Reduce Transparency and in full screen
    • Sizes the macOS tab bar from the window's own title bar, and places it below the menu bar in full screen
    • Grows the macOS tab bar under ui_style: terminal to whole rows around the window buttons
    • Requires Qt 6.9 or later for the GUI on macOS; configure rejects an older Qt there
    • Adds pane cards with headers once a tab is split: the program, its working directory, its status, and split, zoom and close buttons on hover. A single pane stays edge to edge
    • Shows the focused pane by dimming the others instead of an outline
    • Makes the gap between panes the divider, with a wider grab area and a grabber on hover
    • Adds chrome_density: comfortable | minimal; Minimal draws 1-pt split lines without headers (hold Option or Alt to show them over the panes) and, on macOS, a bare band in the terminal background for a single tab
    • Replaces the 'press any key' notice of a pane whose shell ended early, failed to start or lost the daemon with a footer offering Restart and Close; Return restarts the pane in place
    • Shows a reconnecting pane as dimmed with a 'Reconnecting to …' pill
    • Groups the command palette's rows (Pane, Tab, Window, Layouts, Blocks, Profiles, Hosts, Edit, View, Shell, Contour), most recently used first.
    • Collapses commands that take a name, such as Change Profile, Launch Layout, Attach to Host and Switch to Tab, into one row that opens their list; typing a name at the top still finds and runs it directly. Escape steps back.
    • Redraws the palette at 640 points with one-line rows and the selected command's description in a footer, and opens it with a short scale and fade, a fade only under Reduce Motion.
    • Adds regular-expression and whole-word search to the find bar, beside match case; an invalid pattern says so in the count
    • Counts search matches in steps, so a long scrollback or a heavy pattern no longer freezes the window, and the count fills in as it goes
    • Searches match across wrapped lines, wide characters and accented letters however they were composed
    • Paints search matches yellow in contour-dark and contour-light, the current one stronger
    • Places the find bar at the active pane's top right under its header, moving it out of the way of the current match; under ui_style: terminal it takes the pane header row
    • Adds ⌘F, ⌘G, ⇧⌘G and ⌘E (Use Selection for Find) on macOS; Find Next and Find Previous wrap and open the bar when nothing is being searched for. Adds the SearchSelection action
    • Asks every permission (font change, large paste, buffer capture, host status line, rerun) in one dialog that names the action, with a preview of a large paste and a checkbox to stop asking for the session; questions are asked one at a time.
    • Shows configuration reload errors in the window, with a button that opens the file, and confirms copies, refused pastes and saved layouts with a short notice that screen readers announce.
    • Asks extension and control consent in the same dialog, with the permissions that can type shown in bold.
    • Save Layout says what it saves, stays disabled for an empty name, and asks before replacing an existing layout.
    • Refuses a buffer capture in a daemon-hosted pane instead of leaving the program waiting for the reply.
    • Draws a Linux header bar on GNOME, KDE Plasma and other Linux desktops: the tabs inline as pills, a new-tab button leading (a secondary click on it opens the profiles), search and a main menu holding the six menu-bar menus trailing, and the window's top corners rounded while it is windowed under client-side decorations
    • Places the window buttons in the desktop's order and on its side, from GNOME's button layout, KWin's configuration or GTK's settings.ini, with close alone on the right where none is set
    • Follows the desktop's accent colour, light or dark style, high contrast and reduced animation through the XDG Settings portal, live as they change; without a portal Contour starts as before, with the default accent

    0.8.0 (2026-10-23)

    Contour 0.8.0 turns the shell's command history into something you can see and act on: command blocks with exit-status marks, output folding, a gutter with line numbers and timestamps, a sticky command header and finish notifications, driven by OSC 133 or, on recent systemd, by OSC 3008 context tracking with no setup at all. It detects URLs and file paths in terminal output and opens them with Ctrl+click, replaces the search prompt with a GUI-native find bar, and adds kitty graphics animation frames. Terminal output throughput is up several-fold, reflow and resize keep text and the cursor where they belong, and a broad round of fixes covers Windows, Flatpak, daemon mode, SSH and the settings page.

    • Adds "Copy Last Command" to the terminal's context menu, copying the last finished command's command line without the prompt in front of it; "Copy Last Prompt" copies the prompt's lines, PS1 included
    • Adds the profile option copy_command_preserve_multiline to preserve line breaks and tabs when using Copy Command. Disabled by default.
    • Adds history.hard_limit, which makes the scrollback evict a whole command at a time. Anything above history.limit is headroom the buffer may grow into; when it fills, entire (prompt, output) blocks are dropped from the top instead of a slice taken wherever the limit happened to fall, so the oldest line kept is a prompt with its command's output intact rather than an orphaned tail. Boundaries come from the shell's OSC 133 marks, so with no shell integration — or for a single command whose output is larger than the whole headroom — the buffer simply bounds at hard_limit and evicts line by line as before. Defaults to history.limit, which is exactly today's behaviour (#836)
    • Changes Vi normal mode to move in visible lines, stepping over collapsed blocks; folding.on_jump_into_fold picks whether a search hit inside one expands it or is skipped
    • Changes Vi normal mode's mm to set a user mark rather than a prompt mark: it is drawn as ◆ in the gutter and as a tick on the scrollbar, and no longer counts as a command boundary for folding or for history.hard_limit's eviction of whole commands, while [m, ]m and the im/am text objects still visit both kinds (#1010)
    • Changes the default scrollbar.position from Hidden to Right, so the command marks on the scrollbar are visible from the start. The scrollbar floats over the terminal's edge without taking a column, appears only while there is history to scroll through, and hides on the alternate screen unless hide_in_alt_screen is turned off. The new default applies to new configurations: a contour.yml written by an earlier version keeps scrollbar.position: Hidden, because Contour writes out the full default configuration on first run, so set position: Right in the profile's scrollbar section, or pick right for "Scrollbar position" on the settings page, to see the marks (#1010)
    • Fixes stale fold ranges after a command finished: OSC 133's ;B and ;D wrote their line flag without invalidating the ranges derived from it, so anything reading them between the end of a command and the next prompt saw the state from before
    • Fixes CopyLastCommandOutput on output of only blank lines putting a bare newline on the clipboard

    Context tracking (OSC 3008)

    • Adds support for OSC 3008, systemd's hierarchical context signalling (UAPI.15): the nested stack of contexts a shell, run0, ssh or a container runtime opens around whatever runs inside it. systemd 258 and later emit these around every interactive command with no configuration at all, so on such a system Contour learns command boundaries, exit statuses and working directories for free (#2078)
    • Adds the {Context} indicator status-line placeholder: a breadcrumb of the contexts above the one you are typing in. It shows only privilege and machine boundaries by default and draws nothing at all when there are none, so an ordinary shell session is unchanged
    • Adds an optional tint map to color schemes, giving the page background a different shade under an elevated, containerised, virtualised or remote context. No shipped scheme sets one, deliberately: every field OSC 3008 carries is a display hint any program on the terminal can write, so the colour is something you opt into rather than something that appears
    • Adds fold controls, mark-jump stops and "copy last command output" to prompts without any setup on a system where OSC 3008 arrives and no shell integration is installed. A shell integration, if one is installed, keeps full ownership of the markers and nothing changes
    • Adds reporting of how a command really ended: OSC 3008 distinguishes a crash from an interruption from a plain non-zero exit, and names the signal — which OSC 133's numeric exit code cannot express
    • Changes the tab tooltip and "Open Current Folder" to follow the working directory OSC 3008 reports. A directory belonging to a container, a VM or another machine is never opened locally — the menu entry greys out rather than opening the host's directory of the same name. Set osc_context.enabled to false to opt out of all of it
    • Adds the same context tracking, tinting and breadcrumb to a contour attach pane that a local one gets

    New VT sequences and protocols

    • Removes the deprecated SETMARK sequence (CSI > M); use OSC 133 ; A instead
    • Adds DECSWBV (CSI Ps SP t), the VT520 sequence for setting the warning-bell volume: Ps 1 silences the bell, 2 to 4 halves it, 0, an omitted Ps or 5 to 8 keeps it at the profile's configured volume. An application can only mute or halve that volume, never raise it, and RIS restores the default (#732)
    • Adds DECSMBV (CSI Ps SP u), the VT520 sequence for setting the margin-bell volume: Ps 0, 1 or an omitted Ps silences it (the default, per the VT510 manual), 2 to 4 halves it, 5 to 8 sets it to high, and RIS restores the default. Contour does not yet ring the margin bell itself — DEC private mode 44 remains unimplemented — so for now this only stores the value for when it does (#733)

    • Fixes a full-page scroll down (SD, or a reverse index on the top row) erasing the newest lines of the scrollback and moving the lines pushed off the bottom into its oldest slots. The scrollback now stays as it was, as in xterm, Windows Terminal, kitty and WezTerm

    • Fixes clearing the scrollback (ED 3) leaving the view scrolled to, or the vi cursor on, rows that no longer exist, and a hint session open over the history matching them
    • Fixes writing to the host-writable status line after a narrowing resize writing past the end of its row, out of bounds in release builds
    • Fixes a DEC macro that invokes itself hanging the terminal, and a macro body larger than the free input buffer overflowing it
    • Fixes DEC macros (DECDMAC, DECINVM) to follow DEC STD 070: a macro runs where it is invoked, as if its bytes had come from the host, rather than after the rest of the output; the definitions share 6 KiB of macro space, whose room left DECMSR now reports (it said 0), and DECCKSR reports their checksum (it said 0000); a definition with a parameter out of range or a body that is not hex, or one made inside a running macro, is ignored whole; a body keeps no control characters; and the hex repeat sequence !     • Fixes a full reset (RIS) keeping the macros, the user-defined keys and the soft character set while a soft reset (DECSTR) cleared them, the wrong way round by DEC STD 070, the VT520 manual, xterm and Windows Terminal. A RIS inside a running macro now ends it, and DECMSR and DECCKSR are answered from VT420 on only, as in xterm
    • Fixes VT screenshots (ScreenshotVT): a wide character replayed one column too far right, the line break after the last row scrolled the first row away on replay, OSC 66 text came back at ordinary size, and screenshot.vt drew from wherever the replaying terminal's cursor stood, in its colors and modes. The file now starts from a reset, cleared page
    • Fixes XTGETTCAP replies spelling a byte past ASCII, such as an 8-bit CSI, as FFFFFF9B instead of 9B
    • Fixes narrowing the window moving the cursor to the right: each column step doubled its column until it was pinned at the right edge, where anything printed before the application next moved it landed. Released versions showed this only with reflow_on_resize off

    Stability, performance and startup

    • Improves terminal output throughput, fed from memory: plain text 166.6 → 310.9 MiB/s, coloured text 42.7 → 281.9 MiB/s, full-screen applications on the alternate screen 55.6 → 593.2 MiB/s. Lines with mixed colours and the alternate screen now take the bulk-text path, plain-text stretches inside non-ASCII text are written in bulk too, scrollback lines that scroll out are reused instead of reallocated, escape-sequence parameters are scanned in bulk, and each sequence is looked up through an index instead of a binary search
    • Improves reading from the terminal's PTY: the parser keeps reading while a frame is being built instead of waiting for it, and a burst of output schedules one redraw instead of one per read; plain text through a real PTY 69.8 → 104.2 MiB/s
    • Changes the default read_buffer_size from 16384 to 65536 bytes: the most read from the PTY and parsed in one go. Hosts that start sessions without a configuration file, such as contour daemon, move from 4096 to 65536 bytes
    • Fixes Contour not exiting for up to a minute or more after its window closed on systems where opening a GPU device hangs (seen with nouveau): loading Qt Multimedia for the bell no longer probes the GPUs for hardware video decoding and encoding
    • Fixes Vi mode's commands and mode switches changing the terminal from the GUI thread without its lock, racing with a program's output (a mode switch resized the page in the middle of it); a light/dark switch re-seeded the palette the same way
    • Fixes Contour hanging while local echo was on (SRM reset): SendChars hung on every use, and with in-band resize reports (mode 2048) on as well, so did toggling the status line, the key maps or input protection, changing the font size or resizing the window, entering Vi normal mode and switching back to the tab.     • Fixes a reply that Contour raised from the GUI rather than from a program's output waiting for the next key press or output before it was sent, so a program blocked reading it could wait forever: the answer to an OSC 99 notification being closed or clicked, and the selection report of DECSET 2030 for SelectAll, CreateSelection or a drag that scrolls the view
    • Fixes a function key from F6 to F20 occasionally crashing Contour while a program redefined the user-defined keys (DECUDK) or reset the terminal: the key read the table as output rewrote it. Typing and the key-binding lookup also read the keyboard lock (KAM), local echo (SRM), auto-repeat and the modes a binding matches on, such as application cursor keys, while output could change them
    • Fixes an out-of-memory kill of any process running inside Contour, such as a compiler or a language server, closing Contour and every tab with it on desktops that start applications as systemd units.     • Fixes closing a terminal whose shell could not be started, which made Contour wait for any other process it had started to exit and, on builds with standard library assertions enabled, abort. A process that was never spawned held the id 0, which POSIX reads as the caller's whole process group
    • Fixes a key press occasionally crashing the terminal, and a reply to the application occasionally losing its first bytes, which Neovim hit at startup: its DA1 query came back as just "2;314c" and was read as typed keys. Input flushes from the parser thread and the GUI thread could overlap, and each discarded the bytes both had written, so the next reply started that many bytes late; a key press shorter than that crashed. Flushes are now serialized
    • Fixes a crash (debug builds) or out-of-bounds memory access (release builds) when long or wrapping output reached past the 80th column right after startup: startup widens the page before it makes it taller, and the lines the taller page took over from the unused scrollback kept their old, narrower width.     0.7.0 (2026-08-17)

    Contour 0.7.0 makes the window a workspace: native GUI tabs in the title bar, split panes, saved layouts, and an optional terminal-styled UI that draws the application's own chrome on the character grid. It adds an experimental daemon mode for sessions that outlive the window showing them, accessibility support across the terminal and its chrome, the kitty graphics, text-sizing and clipboard protocols, ReGIS vector graphics, and a large round of VT conformance work.

    Tabs, splits and layouts

    • Adds first-class GUI tabs presented in a custom window title bar, replacing the status-line tab list (the {Tabs} status-line directive remains supported for existing configs)
    • Adds split panes — split the active pane vertically (Ctrl+Shift+E) or horizontally (Ctrl+Shift+O), close a pane (Ctrl+Shift+X), and move pane focus with Alt+Shift+Arrow
    • Adds pane management actions: swap the active pane with a neighbor (Ctrl+Alt+Arrow), resize it (Ctrl+Shift+Alt+Arrow), flip a split's orientation (Ctrl+Shift+Backslash), and move a pane to a new position in the split tree (unbound by default)
    • Adds pane zoom (TogglePaneZoom, Ctrl+Shift+Z): gives the active pane the whole tab area, hiding its siblings, and toggles back to the tiled layout. Moving pane focus while zoomed keeps the zoom and shows the newly focused pane; splitting, closing or rearranging panes returns to the tiled view. A zoomed tab is titled after the pane on screen and wears a Z badge
    • Adds dragging tabs: reorder a tab within its strip, drag it into another window, or tear it out into a new window, with a live drop-position indicator showing where it will land; the running terminal survives the move (within the same process)
    • Adds renaming a tab by double-clicking it, and a color-swatch picker in its context menu. The picker is keyboard-driven — the cursor keys and the vim motions h/j/k/l walk the swatches, Enter or Space picks the highlighted one, Escape dismisses — and opens on the color the tab already wears
    • Adds the actions SetTabColor and ResetTabColor, so coloring a tab is no longer mouse-only: both appear in the command palette, and either can be bound in input_mapping. SetTabColor opens the tab's color picker, or applies a color outright when given one (for example { mods: [Shift,Control], key: 'R', action: SetTabColor, color: '#ff0000' })
    • Adds configurable layouts: named sets of tabs with per-tab command, working directory, name, color, profile, and split panes; open at startup via default_layout, via --layout NAME, or the LaunchLayout action. SaveLayout writes the current window's tabs back into layouts.yml, prompting for a name when none was given — and is reachable from the command palette, so saving a layout needs no keybinding
    • Adds the dim_unfocused profile option: dims a pane while it is not the focused one (an inactive pane of a split, or any pane of an unfocused window) by blending it toward its background color; 0.0 (default) disables dimming
    • Adds the top-level options tab_bar_position (Top/Bottom) and tab_bar_visibility (Always/Never/Multiple), to place the GUI tab bar at the top or bottom of the window and to hide it entirely or show it only when more than one tab is open
    • BREAKING: tab_bar_position and tab_bar_visibility belong to the top level of contour.yml, not to a profile — a window shows one tab bar whichever profiles its tabs run. If you tried them in a 0.7.0 prerelease, move these two keys out of your profiles: block; a profile-scoped copy is no longer read
    • Adds Ctrl+Tab / Ctrl+Shift+Tab and Ctrl+PageDown / Ctrl+PageUp as tab-switching shortcuts. They reach existing configurations too, and binding them yourself still wins. Note that Ctrl+Tab is now taken from applications that request it through the Kitty keyboard protocol
    • Adds switching tabs with a horizontal mouse wheel tilt or a two-finger trackpad swipe, over the tab strip or the terminal, configurable via the new global tab_switch_on_horizontal_wheel option (default on); an application that requested mouse reporting keeps the horizontal wheel, and the bypass modifier (Shift) switches tabs even then. Also fixes a sideways swipe over the tab bar doing nothing at all on a trackpad
    • Fixes the tab bar placement and visibility settings appearing to do nothing until Contour was restarted

    Window and desktop integration

    • Changes the window to use a custom client-side-decorated title bar (tab strip plus window controls) by default on all platforms; set show_title_bar: true to use the native server-side window decoration instead, in which case the tab strip is kept but its window controls defer to the OS frame
    • Adds window_control_style, deciding how the window's minimize/maximize/close buttons are drawn and which side of the tab bar they sit on — until now always Windows-shaped and always on the right, which on macOS is the wrong corner.     • Fixes the window losing its drop shadow on KDE Plasma. The window now publishes a shadow of its own to KWin, on both X11 and Wayland, sized and shaped like Breeze's so it matches the rest of the desktop; window_shadow sets it to None, Small, Medium, Large or VeryLarge. Only KWin can act on this, so on other compositors and window managers it has no effect
    • Fixes the same loss on Windows and macOS, where it also cost the window its rounded corners.     • Fixes background blur never turning off again on X11 once it had been switched on, and fixes the window border being drawn dark on Windows regardless of the theme setting
    • Fixes multi-monitor handling: the window no longer re-pins itself to the widest screen on every frame, refresh-rate/DPI tracking follows the window's actual screen after a monitor move, and new windows open on the spawning window's screen
    • Changes a display-scale change (moving to a monitor with a different scale, a late Wayland fractional-scale arrival) to preserve the terminal's columns and lines with a single corrective window resize
    • Changes font zoom to keep the window and pane size fixed and adjust the terminal's columns and lines (and the child PTY size) instead of resizing the window
    • Fixes window resize oscillation/flicker: the terminal no longer fights the window manager by resizing its own window from resize events; the grid floors to the given size (sub-cell remainder renders as padding) while X11/macOS keep WM-side cell snapping via size hints
    • Fixes window spawn flicker: the window is sized from the real font metrics before it is first shown and opens directly in the profile's window state, instead of appearing at a default size and jumping
    • Fixes window sizing on tiling Wayland compositors: a freshly-spawned terminal was mis-sized until a manual resize (#1955), and the window snapped back to the configured terminal_size after a screen or scale change (#1941)
    • Fixes programmatic window resizes (CSI 8 t) shrinking the window by the title-bar height on every call, and CSI 4 t resizing the grid without the window; in split windows both now solve the pane layout so the requesting pane receives its exact grid
    • Fixes the KDE forced-font-DPI override being read from the X11 key in Wayland sessions (now honors forceFontDPIWayland) and no longer re-reads the setting file on every frame
    • Fixes the window padding being computed against the wrong scale when a forced font DPI is configured (KDE's "Force font DPI"), which fitted the grid to a width the window did not have and left the terminal's own idea of where the grid starts disagreeing with where it was drawn

    Rendering, fonts and Unicode

    • Improves Unicode width measurement: a grapheme cluster is measured as a whole, so ZWJ sequences, skin-tone modifiers and Indic conjuncts occupy the columns they actually need instead of being sized from their first codepoint. Following terminal-unicode-core, VS16 promotes a cluster to the emoji presentation and may widen it to two columns, while VS15 selects the text presentation without changing the width — a cluster already on screen is never narrowed. Cluster measurement is on by default and can be turned off with DEC mode 2027, which returns width measurement to the classic per-codepoint wcwidth() model
    • Improves font fallback: a character no font in the chain covers is now resolved by asking which installed font actually covers it, rather than giving up at the end of the chain
    • Prefers a monospaced font when falling back, rather than taking whichever font in the chain happens to come first; a proportional font is still used where no monospaced one has the character, so nothing that renders today stops rendering. The strict_spacing setting now genuinely refuses non-monospaced fallbacks, which it previously did not (#1939)
    • Fixes text falling back to the wrong font, and being drawn a cell too far to the left, whenever a run contained a single character the primary font was missing. A prompt such as Claude Code's, where an ornament and a non-breaking space precede the first word, had that whole first word re-shaped in a fallback font. Only the characters the primary font genuinely lacks now fall back, and a glyph can no longer advance the cursor by zero cells (#1939)
    • Fixes a font's weight: and slant: being silently ignored unless spelled exactly one way. The names are now matched without regard to case or separator, so bold, Bold, extra_bold, extra bold and ExtraBold all work — including the CamelCase spellings that contour generate config itself writes, which previously did not load back. The alternate names each weight is also known by (regular, ultralight, semilight, semibold, ultrabold, ultrablack) are accepted too, and a value that still cannot be read is now reported instead of quietly leaving the default in place
    • Deprecates slant: thin. It never named a slant — it reached the table as a copy of the weight list — and continues to mean normal, now with a warning
    • Fixes the terminal reporting a bold-italic font to the application (OSC 50) as merely italic, dropping the weight from the pattern
    • Fixes curly underlines being drawn almost as tall as a lowercase letter and running into the text above them on fonts that declare line spacing, such as the default "monospace" on many Linux systems (#1754), and fixes the other underline styles sitting one row too high, on the baseline itself — the upper stroke of a double underline could be drawn inside the letters, a dotted underline came out as dashes or vanished entirely, and a double underline's strokes were a pixel too thin at even thicknesses
    • Fixes combining marks vanishing from uniformly styled lines: a character written in decomposed form, such as a Greek or Cyrillic letter followed by a combining accent, was drawn as its base letter alone, because the batched rendering path those lines take can only carry one codepoint per column
    • Fixes selecting text changing how wide a glyph is drawn, so that emoji and other multi-codepoint characters no longer gain padding and push the rest of the line to the right when highlighted (#1752)
    • Fixes a tall glyph — a Nerd Font icon, a powerline separator — overwriting a neighbouring glyph in the texture atlas, and no longer shifts such a glyph sideways off its own bearing
    • Fixes characters rendering as other characters, or shrunken and unreadable, on a pane whose size has changed a lot: the glyph cache was built once for the original size, so a window maximized from small, or a pane given most of the tab, could need more slots than it held and glyphs began overwriting each other mid-frame. The cache is now resized along with the page, and splitting no longer builds each pane's cache at the wrong size only to rebuild it immediately (#2040)
    • Fixes a pane rendering blank or partially after a font, font-size or DPI change that reached it while it was not on screen — minimized, occluded, or on another tab. The pane kept shaping text with fonts it had already discarded, and the frame was dropped instead of drawn
    • Fixes the status line and non-displayed pages being drawn against whichever screen was current rather than the one being rendered, which took the cursor row and the cursor colour from the wrong page
    • Fixes searching for text outside Latin-1: a needle such as "Привет" or an emoji drove the case handling through functions that are undefined for those codepoints, which could silently mismatch or abort the terminal. Case is now folded per the Unicode character database, so "smart case" and case-insensitive search work for non-Latin scripts as well
    • Fixes Unicode characters sometimes being wrongly decoded during high-bandwidth output

    Stability, performance and startup

    • Fixes Contour taking minutes to open on a desktop whose notification daemon is installed but not running — the case when dunst is disabled, for instance. Each terminal session asked the desktop about notifications synchronously as it was created, and with nothing there to answer, every one of them waited out D-Bus's 25-second reply timeout before any window could appear; a window with several tabs paid it once per tab. Desktop notifications are now sent without ever waiting for a reply, so an absent or wedged notification daemon costs nothing at startup, and can no longer freeze the terminal for the same 25 seconds when a program raises a notification or rings the bell. A notification daemon that starts after Contour did is now picked up too
    • Fixes multi-second shell startup stall when the shell (e.g. fish) queries terminal capabilities before the display is attached — queued replies are now flushed on display attach instead of waiting for the next focus/input event
    • Fixes a hang and a crash on startup when probing the audio device, for profiles that cannot ring an audible bell
    • Improves PTY throughput performance determinism by rewriting the internal grid cell storage
    • Fixes crashes and heap corruption when rapidly changing the font or window size, caused by data races between the UI thread and the Qt Scene Graph render thread; geometry/font changes are now deferred and applied on the render thread (#1922, probably #1712, #408)
    • Fixes Contour aborting when a pane was closed or a tab switched while a frame was being drawn: closing a split pane could take the whole window down, because the drawing thread was reading the session the closing pane had just given up. A tab switch could likewise draw one frame out of two different terminals
    • Fixes a crash when closing a tab, window or split pane, in the moment between the shell exiting and the session being destroyed: the thread watching for that exit was asked to stop but never waited for, and destroying it while it still ran aborted the application
    • Fixes a crash on Windows when opening a new tab, window or split pane while the shell could not be started there — most visibly from a WSL or SSH session, or with a shell such as nushell. Such a spawn now retries in Contour's own directory before falling back to the login shell, and if it still cannot start, the reason is shown in the pane and the pane closes on a key press, rather than taking the whole application down
    • Fixes a crash on Windows when opening a new tab or split from a pane that had reported its working directory over OSC 7 — a remote directory from an SSH session that does not exist locally, or the raw file:// URL handed to CreateProcess() instead of the extracted path. A working directory is now only inherited when it exists on the local machine
    • Fixes a crash, and a possible window freeze, under heavy output on Wayland: the input method's cursor-position queries were answered from the render thread without locking the grid, racing a concurrent resize or reflow
    • Fixes a crash when entering Vi normal mode (Ctrl+Shift+Space) while an application was producing output, most reliably a remote tmux session over SSH. Showing the indicator status line resizes the page, and that reflowed the grid without locking it against the thread writing into it. The same lock was missing from the scroll, selection, search and paste actions
    • Fixes Contour aborting when an application's font request (OSC 50) was approved after the pane it came from had gone away, or after the window had briefly lost its drawing surface — leaving the dialog open across a pane close, a tab switch or a screen change was enough. The approved font is now remembered as that session's own, so it also survives a configuration reload or a tab rebind instead of silently reverting to the profile's font
    • Fixes the built-in SSH client corrupting its own connection when a key was pressed or the window resized during heavy output, which ended the session with "Decrypt failed" or "Out of boundary" and then filled the log with write errors. The connection is no longer driven from two threads at once, and a failed write ends the session instead of being retried forever. Opening two SSH sessions at the same moment also no longer races the SSH library's one-time initialization
    • Fixes an error being logged on every normal shell exit: a pseudo-terminal master reports its last slave closing as EIO, which is end-of-file rather than a failure
