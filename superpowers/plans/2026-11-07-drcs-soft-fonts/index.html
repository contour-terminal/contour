    DECDLD Soft Fonts, Finished — Implementation Plan

    For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

    Goal: Real-world DECDLD soft fonts load correctly, are sized for the cell they were designed for, render as crisp monochrome masks coloured from each cell's real attributes, keep the underlying characters for copy and search, and work in daemon-hosted sessions and across a live upgrade.

    Architecture: A pure, table-driven font model in vtbackend/vt/ (decoding, sixel accumulation, target-cell detection ported from Windows Terminal, error glyph) is owned by Terminal as a copy-on-write SoftFontStore. A grid cell stores its real codepoint plus a SoftGlyphRef {font, position} in a sparse per-line side table. RenderBufferBuilder resolves that reference to an immutable shared_ptr<SoftGlyph const> under the state lock. A new SoftFontRenderer in vtrasterizer, a sibling of BoxDrawingRenderer, uploads nearest-neighbour scaled alpha tiles to the shared atlas. The daemon mirrors the store with one capability-gated PDU and the references with an appended Delta field.

    Tech Stack: C++23, Catch2, Qt6 (offscreen verification only), CMake presets.

    Spec: docs/superpowers/specs/2026-11-07-drcs-soft-fonts-design.md. Read it first. It holds every ruling this plan relies on.

    Primary references: - Windows Terminal src/terminal/adapter/FontBuffer.cpp, FontBuffer.hpp, DispatchTypes.hpp and terminalOutput.cpp, pinned at commit cbc857bdf7749981890c5b561ee44ea31948bfb1 (https://raw.githubusercontent.com/microsoft/terminal/<sha>/src/terminal/adapter/FontBuffer.cpp). - The VT510 DECDLD page: https://vt100.net/docs/vt510-rm/DECDLD.html

    Global Constraints

    • Follow AGENT.md: C++23, no C-style loops, [[nodiscard]], Doxygen on new public API, .hpp with #pragma once, enum class with an explicit : uint8_t and the zero value as the off/default case, no bool parameters, configuration at construction time, std::expected for fallible decoding.
    • Zero warnings under -Werror, with clang-tidy clean. No NOLINT. clang-format all C++ files, but never .qml files.
    • vtbackend layering: core/ includes only core/, and vt/ includes nothing above vt/. vthost links no Qt.
    • Never edit vendor/core-cpp.
    • Build with cmake --build --preset clang-asan (on macOS the existing tree is out/appleclang-debug, so use whichever preset is configured). Run tests with ctest --preset=clang-asan.
    • Crisp scaling only: nearest-neighbour, filling the cell exactly on each axis. No filtering.
    • bench-headless instruction counts on ascii, utf8 and tui must not move (spec anti-goal).
    • Do not commit third-party font data (the vt100.net fonts carry no stated licence, and cmatrix is GPL-3). Test fixtures are synthetic sequences that reproduce each real font's header and geometry. The real files are used only in the Task 8 visual check, from a scratch directory.
    • Commits end with Signed-off-by: Christian Parpart <christian@parpart.family>, with no AI trailers.

    Review Focus

    1. Reflow and resize with soft-glyph cells in scrollback. The side table must move with its cells exactly as imageFragments does (LineSoA.cpp copy at ~204). Covered by a test in Task 2.
    2. Overwriting a soft-glyph cell with ordinary text, including the bulk ASCII path and erase (ED/EL/ECH), must drop its reference. Otherwise a stale glyph draws over new text. Covered by tests in Tasks 2 and 3.
    3. ICH/DCH and scrolling regions shifting cells sideways carry the reference with the cell. Covered by a test in Task 2.
    4. Copying a selection across mixed soft and ordinary cells yields the underlying characters. Covered by a test in Task 3.
    5. Font-size change while soft glyphs are on screen, including DECDWL/DECDHL rows. The tiles must regenerate at the new cell size, and the halves must be correct. Covered by a test in Task 5.

    Known and out of scope: larsbrinkhoff's twit.txt/ictech.txt rely on VT220 sixel-column overflow into the next character. Windows Terminal does not support this either.

    Interfaces (Produces):

    // core/SoftGlyphRef.hpp
struct SoftGlyphRef
{
    uint8_t font = 0;     ///< Pfn, 0..2.
    uint8_t position = 0; ///< 7-bit position in the set, 0x20..0x7F.
    auto operator<=>(SoftGlyphRef const&) const = default;
};

// vt/SoftFont.hpp
enum class SoftFontUsage : uint8_t { Text, FullCell };
enum class SoftCharsetSize : uint8_t { Size94, Size96 };
enum class SoftFontErase : uint8_t { AllChars = 0, ReloadedChars = 1, AllRenditions = 2 };
enum class SoftFontError : uint8_t { FontNumber, EraseControl, CellMatrix, FontSet, Usage, CharsetSize, TooLarge, Designator };

struct DecdldParameters { int pfn, pcn, pe, pcmw, pss, pt, pcmh, pcss; };  ///< raw, absent = 0

enum class SoftFontSizeSource : uint8_t { Pixels, Matrix };  ///< Matrix = Pcmw 2/3/4

struct SoftFontDeclaration      ///< validated
{
    uint8_t fontNumber; uint8_t startPosition; SoftFontErase erase;
    uint8_t declaredWidth; uint8_t declaredHeight;     ///< 0 = not declared
    SoftFontSizeSource sizeSource;
    uint16_t columnsPerPage;                           ///< 80 or 132
    uint8_t linesPerPage;                              ///< 24, 36 or 48
    SoftFontUsage usage; SoftCharsetSize charsetSize;
    auto operator<=>(SoftFontDeclaration const&) const = default;
};

[[nodiscard]] std::expected<SoftFontDeclaration, SoftFontError> decodeDecdld(DecdldParameters const&);

struct SoftCellGeometry { uint8_t fullWidth; uint8_t fullHeight; uint8_t textWidth; }; ///< textWidth 0 = unclipped
[[nodiscard]] SoftCellGeometry detectTargetCell(SoftFontDeclaration const&, uint8_t usedWidth, uint8_t usedHeight);

struct SoftGlyph
{
    uint64_t id = 0;                ///< content hash of (width, height, coverage); the atlas key
    uint8_t width = 0, height = 0;  ///< == the font's SoftCellGeometry full size
    std::vector<uint8_t> coverage;  ///< row-major, top row first, 0 or 1
};

struct SoftFont
{
    SoftFontDeclaration declaration;
    std::string designator;                                   ///< Dscs: 0-2 intermediates + final
    SoftCellGeometry geometry;
    std::array<std::shared_ptr<SoftGlyph const>, 96> glyphs;  ///< index = position - 0x20; null = undefined
    std::shared_ptr<SoftGlyph const> errorGlyph;              ///< reverse '?', at geometry size
};

/// Makes a glyph and stamps its content-hash id. The one factory the decoder, the state codec
/// and the daemon mirror all use, so identity never needs persisting or sending.
[[nodiscard]] std::shared_ptr<SoftGlyph const> makeSoftGlyph(uint8_t width, uint8_t height, std::vector<uint8_t> coverage);

/// Assembles a font from already-built glyphs (codec and mirror path; no sixel decoding).
[[nodiscard]] SoftFont makeSoftFont(SoftFontDeclaration const&, std::string designator,
                                    std::array<std::shared_ptr<SoftGlyph const>, 96> glyphs);

/// Builds a font from a DECDLD body (Dscs + sixel data). @p previous is the font
/// currently under this number (for Pe=1 merging), or null.
[[nodiscard]] std::expected<SoftFont, SoftFontError> buildSoftFont(SoftFontDeclaration const&,
                                                                   std::string_view body,
                                                                   SoftFont const* previous);

// vt/SoftFontStore.hpp
enum class SoftGlyphLookup : uint8_t { FontGone, Undefined, Defined };
struct SoftGlyphResolution { SoftGlyphLookup lookup; std::shared_ptr<SoftGlyph const> glyph; }; ///< glyph = error glyph when Undefined

class SoftFontStore
{
  public:
    /// Applies one DECDLD. An invalid sequence leaves the store unchanged and reports why.
    [[nodiscard]] std::expected<void, SoftFontError> define(DecdldParameters const&, std::string_view body);
    void clear() noexcept;                       ///< RIS
    [[nodiscard]] std::shared_ptr<SoftFont const> font(uint8_t number) const noexcept;
    [[nodiscard]] std::optional<uint8_t> fontForDesignator(std::string_view dscs) const noexcept; ///< most recently loaded wins
    /// An out-of-range ref (font > 2, position outside 0x20..0x7F) resolves as FontGone.
    [[nodiscard]] SoftGlyphResolution resolve(SoftGlyphRef) const noexcept;
    [[nodiscard]] uint64_t generation() const noexcept;  ///< bumps on every change
    /// Replaces every font, used by the daemon mirror and the state codec.
    void replaceAll(std::array<std::shared_ptr<SoftFont const>, 3> fonts);
    [[nodiscard]] std::array<std::shared_ptr<SoftFont const>, 3> const& fonts() const noexcept;
  private: ...
};

    Semantics to implement (each pinned by a test below):

    • decodeDecdld:
    • Pfn must be 0..2.
    • Pe must be 0..2.
    • Pcmw: 0 means default, 1 is an error, 2/3/4 are the 5×10, 6×10 and 7×10 matrices (SoftFontSizeSource::Matrix), and 5..16 is a pixel width. A matrix requires usage Text, except 6×10 with 132 columns.
    • Pss: 0/1 = 80×24, 2 = 132×24, 11 = 80×36, 12 = 132×36, 21 = 80×48, 22 = 132×48. Anything else is an error.
    • Pt: 0/1 = Text, 2 = FullCell.
    • Pcmh must be ≤ 32.
    • Pcss: 0 = 94-character set, 1 = 96-character set.
    • Pcn: in a 94-set an absent value means 1, in a 96-set it means 0. Start position = 0x20 + Pcn, which must be ≤ 0x7F.
    • detectTargetCell: port FontBuffer::_calculateDimensions as a data table, one row per known terminal. Do not copy its if ladder.
    cols candidate (w×h) result (full w, full h, text w) only when no size declared
    80 8×10 10, 10, 8 yes
    80 15×12 15, 12, tw no
    80 10×16 10, 16, tw no
    80 10×20 10, 20, tw no
    80 12×30 12, 30, tw no
    132 6×10 6, 10, 0 yes
    132 9×12 9, 12, tw no
    132 6×16 6, 16, tw no
    132 6×20 6, 20, tw no
    132 7×30 7, 30, tw no
    • Fallback: 16, 32, tw.
    • tw = declared width for Text, 0 for FullCell.
    • The table is preceded by three overrides:
      • Matrix → (6, 10, 0) if 132 columns and width ≤ 6, else (10, 10, 8).
      • Declared width and height on a FullCell font → (w, h, 0).
      • Lines ≠ 24 → width 6 at 132 columns / 10 at 80, height 8 at 48 lines / 10 at 36, then tw.
    • A row is in range when: declared height ≤ h if one is declared, else used height ≤ round-up-to-6(h); and declared width ≤ w if one is declared, else used width ≤ w.
    • buildSoftFont:
    • Dscs is 0..2 bytes in 0x20–0x2F followed by one final in 0x30–0x7E. A missing final is a SoftFontError::Designator.
    • Sixel data: ?..~ add a column, / moves down 6 rows, ; ends the character. Every other byte, CR/LF included, is ignored.
    • Accumulate into a 16×32 scratch per character, ignoring columns ≥ 16 and rows ≥ 32. Track the used width and height, then detectTargetCell.
    • Clip text fonts to textWidth and centre them in fullWidth (offset = (fullWidth − textWidth) / 2), as in _packAndCenterBitPatterns.
    • Positions past 0x7F are dropped.
    • Pe=1 with an unchanged declaration, designator and charset size starts from previous->glyphs. Otherwise every glyph starts undefined. Pe=2 is handled by the store.
    • Error glyph: Windows Terminal's 15×23 reverse-question-mark pattern (_generateErrorGlyph's inputBitPattern), scaled nearest-neighbour to fullWidth × fullHeight.
    • SoftFontStore::define:
    • Pe=2 drops every font before loading.
    • Each new SoftFont is a fresh shared_ptr<SoftFont const> (copy-on-write: existing pointers held by render buffers stay valid and unchanged).
    • fontForDesignator picks the most recently loaded match.

    • generation() increments on define, clear and replaceAll.
