    Platform Chord Parity Implementation Plan

    For agentic workers: REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

    Goal: Give every Contour application command a default chord on both Linux/Windows and macOS, translated by platform convention, and make that parity a tested property.

    Architecture: All changes are rows in the data tables keyRows() / charRows() of src/contour/config/DefaultBindings.cpp, plus one new test file that compares the per-platform action sets against a written exemption table. The golden files under src/contour/config/testdata/ are regenerated per task and their diff reviewed by hand. No new mechanism: the ⌃⌘ Mac rows are explicit MacOnly rows with a new CtrlSuper chord constant (the spec left internal-kind vs explicit rows to the builder; explicit rows chosen — one new constant, no new resolution path, nothing the config writer must learn).

    Tech Stack: C++23, Catch2, CMake presets (appleclang-debug on macOS, clang-asan on Linux).

    Spec: docs/superpowers/specs/2026-11-08-platform-chord-parity-design.md

    Global Constraints

    • Every new row is both(...) (RowReach::WrittenAndFallback), except rows needing DeclinedInput::Consume, which are fallback(...) (only fallbacks can consume): ⇧⌘O and Ctrl+Shift+L.
    • New rows apply to both editions (no native2026Only).
    • Rows acting at the shell prompt are PrimaryScreenOnly.
    • No Alt in any macOS character row (existing test "no macOS default relies on Alt for a character key").
    • No macOS row on ⌘Q, ⌘, ⌘H, ⌥⌘H, ⌘M, ⌘X, ⌘S (existing tests).
    • BindingCollisions ("no default chord fires twice") stays green on every platform and edition.
    • Zero warnings (-Werror), clang-format on C++ files, no NOLINT.
    • Commit messages end with Signed-off-by: Christian Parpart <christian@parpart.family>; no AI trailers.

    Files: - Modify: src/contour/config/DefaultBindings.cpp (charRows, the OpenCommandPalette row ~line 308) - Test: src/contour/config/BindingCollisions_test.cpp, src/contour/command/Shortcut_test.cpp, src/contour/config/ConfigSideFiles_test.cpp:155 - Goldens: src/contour/config/testdata/default-bindings-mac-added.txt (regenerated)

    Note: "no default chord fires twice" checks written rows only, so the fallback-only rows (⇧⌘O, Ctrl+Shift+L) are collision-checked solely by these per-chord single-element assertions. They are load-bearing; keep them exact.
