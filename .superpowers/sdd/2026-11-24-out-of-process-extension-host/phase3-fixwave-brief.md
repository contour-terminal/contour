## Critical
1. Apple Silicon: `ControlPage_posix.cpp:142` adopt() requires st_size == 4096, but XNU rounds a POSIX shm object's size up to the VM page (16 KiB on arm64) at ftruncate, and fstat reports the rounded size → every helper exits 71 (HandlesUnusable), every load HostUnavailable. Fix: accept st_size >= ControlPageBytes rounded up to the page size (getpagesize()) on Apple (and generally: size must be at least ControlPageBytes and at most that rounded to the page size — decide and document). adoptRefusesAWrongSize must use a size larger than one page (8192 also rounds to 16384). Leave a comment that phase-4 shared memory must not trust fstat either.
