# (orchestrator::detail::isPlainWindowsName) both apply to one path component. Both test suites read this file,
# so the two copies cannot drift apart.

# One row per line: the value, a TAB, and `accept` or `refuse`. A line starting with `#` is a comment, and an
# empty line is skipped. In the value, `%XX` is the byte with that hexadecimal value, so a control character, a
# TAB or a UTF-8 sequence can be written; `%25` is a `%` itself.
