Cleanup commands: status = git status --porcelain --untracked-files=normal --ignore-submodules=none;
reachable = git for-each-ref --count=1 --contains HEAD refs/heads refs/tags refs/remotes;
opstate = git -c status.displayCommentPrefix=false -c color.status=false status --long; clean = git clean -f -- STATUS.md;
remove@wt / remove@repo = git worktree remove <abs path>, cwd the worktree / the repository.
